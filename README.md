### 🚀 Project Journey

- **[appimage-manager](https://github.com/Cyber-Syntax/appimage-manager)** — ![Status](https://img.shields.io/badge/status-in%20development-orange) A rewrite of the old [my-unicorn](https://github.com/Cyber-Syntax/my-unicorn) repository, with a focus on a more maintainable codebase, functional programming, and a more robust testing suite.
- **[ztarcompress](https://github.com/Cyber-Syntax/ztarcompress)** — ![Status](https://img.shields.io/badge/status-in%20development-orange) I started this project to improve my Python script, [AutoTarCompress](https://github.com/Cyber-Syntax/AutoTarCompress), by creating a cleaner and more maintainable codebase using functional programming.
- **[my-unicorn](https://github.com/Cyber-Syntax/my-unicorn)** — ![Status](https://img.shields.io/badge/status-legacy-lightgrey) An old project that solved my own problem by automating AppImage installations and updates. I am still proud of this project because it taught me a lot during development. I made several design and architectural mistakes with it, so I started writing [appimage-manager](https://github.com/Cyber-Syntax/appimage-manager), a more maintainable codebase based on what I learned.
- **[AutoTarCompress](https://github.com/Cyber-Syntax/AutoTarCompress)** — ![Status](https://img.shields.io/badge/status-legacy-lightgrey) I couldn't find a tool that could automatically create tar archives for selected directories in Linux, so I wrote this Python project to solve a real problem I had. AutoTarCompress is a backup and archive management tool for Linux. It supports compressed backups, encryption, extraction, cleanup, and more. I made the same mistake of overengineering it as I did with my-unicorn, so I started a new project called [ztarcompress](https://github.com/Cyber-Syntax/ztarcompress) to create a more maintainable codebase.

Multiprocessing was much easier to integrate and maintain, so I continued developing that version.
- **[WallpaperChanger](https://github.com/Cyber-Syntax/WallpaperChanger)** — One of the first simple projects I started to learn Python. I learned from Atomic Habits that the environment is key to creating good habits, so I made this project to help me study. I still use this script without any issues. This script changes my wallpaper based on the time of day. I set some wallpapers for my workdays and others for my days off. If it is the middle of the week, the script changes my wallpaper to one of my workday wallpapers. If it is Sunday, the script changes my wallpaper to one of my days-off wallpapers.
- ![Archived](https://img.shields.io/badge/Status-Archived-lightgrey) **[BatteryGuardian](https://github.com/Cyber-Syntax/BatteryGuardian)** — I started this project to learn Bash while solving an important problem that Linux did not handle well: battery management. I tried my best to handle it with Bash, but then I realized that Bash was not suitable for writing a battery-management script, so I started version 2 with Python. This project is abandoned, but it taught me the fundamentals of how Linux batteries work, including ACPI.
- ![Archived](https://img.shields.io/badge/Status-Archived-lightgrey) **[fedora-setup](https://github.com/Cyber-Syntax/fedora-setup)** — A Bash script for configuring stuff on fedora linux distro. After writing this project, I decided to use Python to create a more maintainable version for setting up Fedora and Arch Linux, called [auto-penguin-setup](https://github.com/Cyber-Syntax/auto-penguin-setup), because Bash was not a good fit for maintainability and testing.
- ![Archived](https://img.shields.io/badge/Status-Archived-lightgrey) **[find_final_grade](https://github.com/Cyber-Syntax/find_final_grade)** — One of the poorly written Python scripts I created when I was starting to learn Python. I still fix some of the ugly mistakes in this and similar early projects, but I do not worry about them too much anymore. It calculates the final grade when the user enters their midterm grade.
- ![Archived](https://img.shields.io/badge/Status-Archived-lightgrey) **[siyuan-appimage-update](https://github.com/Cyber-Syntax/siyuan-appimage-update)** — This was the first project I published publicly on GitHub. It installs the latest Siyuan Note AppImage version and verifies its SHA-256 checksum.
